## Что умеет программа

- **Полный пайплайн** одной командой: `metadata → чат → аудио → расшифровка →
  сигналы → моменты → клипы → отчёт`.
- **Скачивание чата VOD** напрямую из Twitch GQL (без токена) с добиранием
  пропусков и адаптивным шагом сканирования.
- **Распознавание речи** через `faster-whisper` (CUDA или CPU), с запасным
  движком `openai-whisper`, кешированием и переводом через LLM.
- **Поиск хайлайтов**: активность чата, хайп-фразы, эмоуты, спам, капс;
  громкость и динамика звука; ключевые слова и смех в речи.
- **LLM-ранжирование** (Ollama или любой OpenAI-совместимый API): осмысленные
  заголовки, категории и причины. Без LLM всё работает на эвристике.
- **Нарезка клипов** через `yt-dlp` + `ffmpeg`: качество на выбор, превью,
  вертикальные версии 9:16, вжигание субтитров.
- **Отчёты**: `report.md`, готовая `index.html` с плеерами и локальная
  веб-галерея всех VOD.
- **Мод «Топарашевт»**: оглавление стрима таймкодами вида `2:04:19 - Любимый цвет`.

## Требования

| Что | Зачем | Обязательно |
|-----|-------|-------------|
| **Python 3.11+** | сам инструмент (проверено на 3.11.9) | да |
| **ffmpeg / ffprobe** в `PATH` | скачивание аудио, нарезка, превью | да |
| **Windows** | инструкции и `run.bat` заточены под неё | да (Linux/macOS — запуск через `python -m ...`) |
| `faster-whisper`, `yt-dlp`, `numpy`, `soundfile`, `loguru`, `fastapi`, `uvicorn` | из `requirements.txt` | да |
| **Ollama** или OpenAI-совместимый API | осмысленные заголовки/категории | нет (по желанию) |
| **NVIDIA GPU + CUDA-библиотеки** | быстрая расшифровка многочасовых стримов | нет (иначе CPU) |
| **PyQt6** | графическое окно (см. ниже) | нет, но настоятельно желательно |
| **PyInstaller** | только для пересборки exe (`build_exe.ps1`) | нет |

## Установка (Windows)

Все команды выполняются в корне проекта через **cmd** или
PowerShell.

### 1. Python

Поставьте Python 3.11+ с https://www.python.org/downloads/ (галочка
«Add python.exe to PATH»). Проверка:

```bat
python --version
```

### 2. ffmpeg

```bat
winget install Gyan.FFmpeg
:: или: choco install ffmpeg
```

После установки **перезапустите терминал** и проверьте:

```bat
ffmpeg -version
```

### 3. Зависимости Python

```bat
python -m pip install -r requirements.txt
```

### 4. (Опционально) Запасной движок распознавания

Если `huggingface.co` недоступен и веса `faster-whisper` не качаются —
поставьте `openai-whisper`, он берёт веса с CDN OpenAI:

```bat
python -m pip install openai-whisper
:: затем добавляйте флаг: --asr-backend openai-whisper
```

### 5. (Опционально) Ускорение на GPU

`faster-whisper` работает на CUDA через CTranslate2. Нужны DLL `cublas64_12.dll`
и т.п. Ставятся так:

```bat
python -m pip install nvidia-cublas-cu12
```

Проект сам находит папки `site-packages\nvidia\*\bin` и подключает их
(см. `utils.enable_cuda_dll_dirs`) — вручную прописывать `PATH` не нужно.
Если CUDA недоступна, пайплайн просто продолжит на CPU.

### 6. (Опционально) Ollama для заголовков

Мод `toparachevt` и качественные названия моментов опираются на локальную LLM.
По умолчанию используется кастомная модель
`Qwythos-9B-v2-Heretic:Q4_K_M` — установка описана в разделе
[Кастомная модель](#кастомная-модель-qwythos-9b-v2-heretic-q4_k_m).

```bat
winget install Ollama.Ollama
```

Ollama по умолчанию слушает `http://127.0.0.1:11434` — этот адрес используется
по умолчанию, отдельно прописывать его не нужно.

## Проверка окружения

Перед первым запуском убедитесь, что всё на месте:

```bat
python scripts/probe_env.py
```

Скрипт проверит:

1. доступность Twitch GQL (метаданные и чат на живом VOD);
2. `faster-whisper` на CUDA и CPU;
3. доступность Ollama и список моделей;
4. наличие `ffmpeg`, `yt-dlp` и версии Python-пакетов.

Отдельные диагностики (нужны при проблемах с чатом):

```bat
python scripts/smoke_api.py [video_id] [секунд]   :: метаданные + пробная загрузка чата
python scripts/diag_chat.py <канал>               :: доступность чата на свежих VOD
python scripts/diag_fields.py <video_id>          :: какие поля схемы чата валидны
```

## Быстрый старт

**Вариант 1 — с окном (проще всего):**

```bat
:: 1. Зависимости (одноразово)
python -m pip install -r requirements.txt

:: 2. Открыть GUI
gui.bat
```

Дальше всё в окне: выбрать режим, указать ссылку/канал/файл мышью,
нажать «Запустить» — лог и статусы будут прямо в программе.

**Вариант 2 — без Python вообще:** взять готовый `dist\TwitchAIClipper.exe`
(см. [Готовый exe](#готовый-exe-без-python)) и запустить двойным кликом.

**Вариант 3 — консоль:**

```bat
:: 1. Зависимости
python -m pip install -r requirements.txt

:: 2. Проверка окружения
python scripts/probe_env.py

:: 3. Полный прогон «как есть» (ID, ссылка или канал)
run.bat run twitch.tv/ссылка

:: 4. Открыть результат в браузере
run.bat serve
:: -> http://127.0.0.1:8765/
```

`run.bat` — это обёртка, которая включает UTF-8 (кириллица в консоли перестаёт
быть «кракозябрами») и вызывает `python -m twitch_ai_clipper %*`. Все
аргументы передаются как есть, поэтому `run.bat run ...` эквивалентно
`python -m twitch_ai_clipper run ...`.

## Как задать цель (VOD)

В командах `run`, `chat`, `transcribe`, `detect`, `clip` первым аргументом идёт
«цель». Понимаются три формата:

| Формат | Пример | Поведение |
|--------|--------|-----------|
| ID видео | `123456789` | берётся конкретный VOD |
| Ссылка на VOD | `https://www.twitch.tv/videos/123456789` | ID извлекается автоматически |
| Имя канала | `twitch.tv/tarik` или `tarik` | берётся **последняя** запись канала |
| **Локальный файл** | `C:\videos\stream.mp4` или `.\my.mkv` | видео читается **с диска**, без скачивания |

Посмотреть последние записи канала:

```bat
run.bat list tarik -n 10
```

Результаты каждого VOD складываются в отдельную папку `output/<vod_id>/`.

### Локальное видео вместо ссылки Twitch

Если в качестве цели передать путь к существующему видеофайлу, программа **не
качает VOD через yt-dlp**, а работает прямо с файлом на диске:

```bat
:: полный путь
run.bat run "C:\videos\stream.mp4" --whisper-model medium --max-clips 10

:: путь можно «вставить» из Проводника — кавычки снимаются автоматически
run.bat run D:\Downloads\мой_стрим.mkv

:: ручная нарезка по своим таймкодам
run.bat clip "C:\videos\stream.mp4" --timecodes 0:10-0:45=Начало
```

Что меняется при локальном файле:

- **Аудио** извлекается из файла через `ffmpeg` (yt-dlp не нужен и не требуется сеть).
- **Клипы** нарезаются локальным `ffmpeg` по секундам, без `--download-sections`.
- **Чат** недоступен (у файла нет чата Twitch), поэтому детект моментов опирается
  на **звук и речь**; в отчётах ссылки `?t=` на Twitch заменяются на таймкоды.
- Имя папки результата берётся из имени файла (`output/<имя_файла>/`).

Нужен только `ffmpeg`/`ffprobe` в `PATH` (см. [Установка](#установка-windows)).

## Настройки: config.toml

Настройки берутся по приоритету (побеждает то, что правее):

```
значения по умолчанию → config.toml → переменные окружения → флаги CLI
```

- `config.example.toml` — подробный пример со всеми секциями и комментариями.
- `config.toml` — **ваша локальная** конфигурация. В репозиторий не попадает
  (он в `.gitignore`); создаётся копированием примера — см. команду ниже.
  Если файла нет, программа работает на значениях по умолчанию
  (`language = "ru"`, `llm_provider = "auto"`).

Чтобы начать с чистого листа — скопируйте пример:

```bat
copy config.example.toml config.toml
```

Путь к конфигу можно задать явно: `--config путь\к\config.toml`.

### Основные секции

**`[general]`** — `output_dir`, `limit_seconds` (0 = весь стрим, N = первые N
секунд для теста), `mode` (например `toparachevt`).

**`[chat]`** — `chat_stride` (шаг сканирования «тихих» мест, сек),
`chat_delay` (пауза между запросами к Twitch), `chat_gap_audit`.

**`[asr]`** — `whisper_model` (`tiny`…`large-v3` или путь к локальной CT2-модели),
`whisper_device` (`auto|cuda|cpu`), `whisper_compute_type`,
`whisper_beam_size`, `whisper_vad`, `whisper_batch_size` (пакетное декодирование),
`language` (`ru` по умолчанию, `auto` — автоопределение), `translate_to`.

**`[llm]`** — `llm_provider` (`auto|none|ollama|openai`), `llm_model`,
`llm_base_url`, `llm_api_key`, `llm_max_candidates`, `llm_batch`, `llm_timeout`.

**`[detect]`** — `bucket`, `top_candidates`, `min_gap`, `max_clips`,
`min_moments`, `clip_length`, `clip_padding`, `min_clip_length`, `max_clip_length`.

**`[cut]`** — `quality`, `vertical`, `burn_subs`, `precise_cut`, `cut_workers`,
`thumbnail`.

### Переменные окружения

| Переменная | Значение |
|-----------|----------|
| `OPENAI_API_KEY` | ключ для OpenAI-совместимого API |
| `OPENAI_BASE_URL` | адрес API OpenAI |
| `OLLAMA_BASE_URL` | адрес Ollama (по умолчанию `http://127.0.0.1:11434`) |
| `HF_ENDPOINT` | зеркало HuggingFace (например `https://hf-mirror.com`) |
| `TWITCH_CLIP_OUTPUT` | папка результатов |

## Команды CLI

```bat
run.bat <команда> [аргументы]
:: то же самое без обёртки:
python -m twitch_ai_clipper <команда> [аргументы]
```

| Команда | Что делает |
|---------|-----------|
| `run <VOD\|ссылка\|канал> [опции]` | **полный прогон**: чат + речь + детект + клипы + отчёт |
| `chat <VOD>` | только чат → `chat.jsonl` (`--dump-chat` ещё и `chat.txt`) |
| `transcribe <VOD>` | только аудио + расшифровка (+ перевод) |
| `detect <VOD>` | только поиск моментов из `chat.jsonl`/`transcript.jsonl` |
| `clip <VOD> [--timecodes ...]` | нарезка по `moments.json` или по своим таймкодам |
| `report <vod_id>` | пересобрать `report.md`/`index.html` из `moments.json` |
| `list <канал> [-n 10]` | последние записи канала |
| `serve [--port 8765]` | локальная веб-галерея результатов |

Общие флаги (доступны в `--help` каждой команды):

```bat
--config <файл>                 :: путь к config.toml
-v, --verbose                   :: подробный лог
--version                       :: версия программы
```

### Флаги команды `run`

Все команды с целью (`run`/`chat`/`transcribe`/`detect`/`clip`) принимают общий
набор флагов, а `run` — ещё и настройки детекта/нарезки.

| Флаг | Что делает |
|------|-----------|
| `-o, --output-dir <папка>` | папка результатов (по умолчанию `output/`) |
| `--whisper-model <модель>` | `tiny`…`large-v3` или путь к локальной CT2-модели |
| `--asr-backend <auto\|faster-whisper\|openai-whisper>` | движок распознавания |
| `--strict-asr` | падать с ошибкой, если модель не загрузилась |
| `--models-dir <папка>` | куда складывать/откуда брать веса моделей |
| `--hf-endpoint <url>` | зеркало HuggingFace (например `https://hf-mirror.com`) |
| `--device <auto\|cuda\|cpu>` | устройство для Whisper |
| `--compute-type <...>` | `auto\|float16\|int8_float16\|int8\|float32` |
| `--language <ru\|en\|auto>` | язык стрима (по умолчанию `ru`) |
| `--translate-to <язык>` | перевести расшифровку через LLM |
| `--llm <auto\|none\|ollama\|openai>` | провайдер LLM |
| `--llm-model <имя>` | модель (например `Qwythos-9B-v2-Heretic:Q4_K_M`) |
| `--llm-base-url <url>` | URL API (Ollama или OpenAI-совместимый) |
| `--llm-api-key <ключ>` | ключ API (или переменная `OPENAI_API_KEY`) |
| `--quality <best\|1080p60\|1080p\|720p60\|720p\|480p\|360p\|audio>` | качество нарезки |
| `--cookies-from-browser <chrome\|firefox\|edge>` | cookies для приватных/закрытых VOD |
| `--limit-seconds <N>` | анализировать только первые N секунд (быстрый тест) |
| `--force` | игнорировать кеш и переделать всё заново |
| `--bucket <сек>` | окно агрегации сигналов (по умолчанию 5) |
| `--clip-length <сек>` | целевая длина клипа |
| `--max-clips <N>` | максимум клипов |
| `--min-moments <N>` | гарантированно выдать не меньше N моментов |
| `--preset <sparse\|dense\|full>` | готовая раскладка плотности |
| `--min-clip-length <сек>` | минимальная длина клипа |
| `--max-clip-length <сек>` | максимальная длина клипа |
| `--min-gap <сек>` | мин. расстояние между клипами |
| `--top-candidates <N>` | сколько кандидатов брать до отбора |
| `--clip-padding <сек>` | запас до/после момента |
| `--vertical` | версии 9:16 (Shorts/TikTok) |
| `--burn-subs` | вжечь субтитры из транскрипта |
| `--precise-cut` | точная резка по кадрам (медленнее, ровнее) |
| `--no-clips` | только анализ, без скачивания видео |
| `--dump-chat` | дополнительно сохранить `chat.txt` |
| `--mode <MODE>` | оформление таймкодов и раскладка (`toparachevt`) |
| `--chat-stride <сек>` | шаг сканирования чата в «тихих» местах |

Примеры:

```bat
:: полный прогон с русской моделью и 10 клипами
run.bat run https://www.twitch.tv/videos/123456789 --whisper-model large-v3 --language ru --max-clips 10

:: быстрый тест: только первые 15 минут, 5 клипов, вертикальные версии
run.bat run 123456789 --limit-seconds 900 --max-clips 5 --vertical

:: только анализ, без нарезки видео
run.bat run twitch.tv/канал --no-clips
```

## Графический интерфейс (GUI)

Настольное окно (PyQt6, тёмная тема в стиле Twitch) — команды вводить не нужно:

```bat
gui.bat
:: или: python -m twitch_ai_clipper gui
```

Что в окне:

- **Команда** — выпадающий список всех 8 режимов (`run`, `chat`, `transcribe`,
  `detect`, `clip`, `report`, `list`, `serve`). Неактуальные для выбранного
  режима поля гасятся и не передаются.
- **Цель** — поле + кнопка «Файл…» (диалог для локального видео): ID, ссылка,
  канал или путь.
- **Параметры** — модель Whisper, язык, провайдер и модель LLM, качество,
  мод (`toparachevt`), пресет, cookies из браузера, лимиты и пороги.
- **Флажки** — `--no-clips`, `--vertical`, `--burn-subs`, `--precise-cut`,
  `--dump-chat`, `--force` (полный флаг — в подсказке при наведении).
- **Живой лог** — вывод пайплайна в окне; «Стоп» убивает и дочерние
  `yt-dlp`/`ffmpeg`. Кнопки «Открыть галерею» и «Открыть папку output».
- настройки **сохраняются автоматически** и восстанавливаются при следующем
  запуске (QSettings).

## Готовый exe (без Python)

В папке `dist\` лежат две самостоятельные программы (собираются PyInstaller-ом,
командой `powershell -ExecutionPolicy Bypass -File build_exe.ps1`):

| Файл | Размер | Что это |
|---|---|---|
| `TwitchAIClipper.exe` | ~185 МБ | окно GUI (двойной клик, без консоли) |
| `TwitchAIClipperCli.exe` | ~233 МБ | консольный CLI (для терминала; GUI запускает задачи именно им) |

Как пользоваться:

1. Положите оба exe в одну папку (GUI ищет CLI рядом с собой).
2. Рядом должен быть `ffmpeg` в `PATH` (см. [Установка](#установка-windows)) —
   как и в python-версии, без него нарезка не работает.
3. Запустите `TwitchAIClipper.exe` — появится окно GUI; либо работайте с
   `TwitchAIClipperCli.exe` в терминале (аргументы те же, что и у
   `python -m twitch_ai_clipper`), например:
   `TwitchAIClipperCli.exe run 123456789 --max-clips 5`
4. Whisper-модели exe скачивает сам при первом запуске в `models/` рядом.
   Отладочный лог windowed-версии: `twitch_clipper_exe.log` рядом с exe.

### Отличия exe от python-версии

- **torch в exe не включён** (иначе сборка раздулась бы до нескольких ГБ).
- Следствие: **расшифровка речи в exe идёт на CPU** — CUDA-библиотеки
  (`cublas` и др.) тоже не упакованы в exe. Если нужен самый быстрый вариант —
  пользуйтесь python-версией (`run.bat`), там GPU работает из коробки:
  `python -m pip install nvidia-cublas-cu12` + `probe_env.py` проверяет.
- `yt-dlp` exe вызывает из PATH (`yt-dlp` или `py -m yt_dlp`), поэтому yt-dlp
  должен быть установлен в системе.

## Мод `toparachevt`

Мод «Топарашевт» делает из стрима **оглавление таймкодами** — ровно в таком виде:

```
2:04:19 - Любимый цвет
2:06:03 - Корм для мужчин
2:07:57 - Нравится ли быть стримерами?
2:12:00 - Маркарян
```

Что меняет мод по сравнению с обычным режимом:

| | `default` | `toparachevt` |
|---|---|---|
| таймкод | `MM:SS`, при часе+ `H:MM:SS` | **всегда `H:MM:SS`** (`0:04:19` вместо `04:19`) |
| заголовок | таблица моментов | **строка `2:04:19 - Название`** |
| плотность | пресет `sparse` | глава ~каждые 2 минуты: `min_gap=60`, `min_moments=150`, `max_clips=300` |
| файлы | `moments.json`, `report.md`, `index.html` | + **`timecodes.txt`** и блок глав в отчёте/галерее |
| `moments.json` | `time`, `timecode` | + `chapter`: `"2:04:19 - Любимый цвет"` |

Запуск:

```bat
:: полный прогон в моде toparachevt
run.bat run twitch.tv/канал --mode toparachevt

:: тот же мод без нарезки — только оглавление
run.bat detect 123456789 --mode toparachevt

:: пересобрать отчёт/таймкоды из готового moments.json
run.bat report 123456789 --mode toparachevt
```

Принимается и алиас `--mode топарашевт` (и частые опечатки вида
`топарашефт`). Мод можно закрепить в конфиге:

```toml
[general]
mode = "toparachevt"
```

> Явные флаги (`--max-clips`, `--min-gap`, …) и `--preset` важнее мода.

### Нарезка по своему списку глав

Список из `timecodes.txt` можно загрузить обратно — одна строка = одна глава
(длина главы = `--clip-length`):

```bat
run.bat clip 123456789 --mode toparachevt --timecodes-file chapters.txt
```

Понимаются строки:

```
2:04:19 - Название          # только начало, конец = start + clip_length
2:18:21- Мазелов            # без пробела тоже
2:04:19-2:06:03=Название    # явный интервал (без '=' дефис в заголовке помешает)
125                         # просто секунды
# комментарий и пустые строки пропускаются
```

### Донарезка отдельных глав (`--only`)

`clip --only` режет только перечисленные главы, но `moments.json`,
`timecodes.txt` и `report.md` остаются **полными** — невыбранные главы просто не
получают `clip_path` и в галерее показываются ссылкой на VOD:

```bat
run.bat clip 123456789 --only 1 2 3   :: нарезать только эти главы
run.bat clip 123456789                :: доделать все остальные
```

### Русские стримы из коробки

- `language = "ru"` — дефолт, автоопределение больше не нужно (оно регулярно
  записывало русскую речь по-английски); отключается флагом `--language auto`.
- `whisper_batch_size > 1` — пакетное декодирование CTranslate2: на стримах
  длиннее часа заметно быстрее. Если CUDA-батчи недоступны (нет `cublas64_12.dll`),
  пайплайн сам переключается на последовательный режим.
- Для лучшего качества русской речи поставьте `whisper_model = "large-v3"` в
  `config.toml` (или флаг `--whisper-model large-v3`) — это связка, которая
  работает по русской речи лучше всего.

## Пресеты и плотность нарезки

Количество моментов ограничено **длительностью стрима и плотностью нарезки**:
на каждый клип нужно `min_clip_length + min_gap` секунд. Программа считает этот
потолок и пишет его в лог.

| Длительность VOD | gap=45, клип 12 с | gap=12, клип 10 с | gap=5, клип 8 с |
|---|---|---|---|
| 10 минут | ~10 | ~27 | ~46 |
| 1 час | ~63 | ~163 | ~276 |
| 3.4 часа | ~217 | ~562 | ~951 |
| 8 часов | ~505 | ~1309 | ~2215 |

Готовые пресеты (`--preset`):

| Пресет | Что это |
|--------|---------|
| `sparse` (по умолчанию) | 15 сильнейших моментов, крупные клипы |
| `dense` | **≈1 клип в минуту**, `min_moments=100`, короткие клипы |
| `full` | максимально подробно, `min_moments=300`, `--bucket 3` |

Либо задайте вручную, например:

```bat
run.bat run 123456789 --min-moments 100 --min-gap 12 --min-clip-length 10 --max-clips 200
```

`--min-moments` важнее `--max-clips`: если моментов не хватает, отбор
автоматически ослабляется (сначала уменьшается разнос, затем берутся все
локальные максимумы).

> Пример: 100 моментов на 10-минутном стриме физически невозможны — максимум ~27.

## Как это работает

Пайплайн `run` (каждый шаг кешируется в `output/<vod_id>/`, `--force` сбрасывает кеш):

1. **Метаданные** — заголовок, канал, длительность, ссылка.
2. **Чат** — скачивание сообщений из Twitch GQL с адаптивным шагом и добором
   пропусков.
3. **Аудио** — дорожка VOD → WAV 16 kHz mono.
4. **Расшифровка** — `faster-whisper` (+ опциональный перевод через LLM).
5. **Сигналы** — слияние чата, звука и текста в карту интересности.
6. **Детект моментов** — кандидаты → ранжирование (LLM или эвристика).
7. **Клипы** — нарезка секций через `yt-dlp` + `ffmpeg`, превью, vertical, субтитры.
8. **Отчёт** — `moments.json`, `report.md`, `index.html`, `timecodes.txt`.

### Как устроен детект

- **Чат** — активность (сообщений/сек), доля хайп-фраз, эмоуты (`KEKW`, `Pog`, …),
  прямые просьбы «clip it / клипай», повторы (спам), капс, уникальные зрители.
- **Звук** — RMS-громкость и её производная (крики, смех, взрывы) по 1 секунде.
- **Речь** — ключевые фразы (`clutch`, `no way`, `офигеть`, `рекорд`, …), смех, капс.
- Всё переводится в робастные z-оценки (медиана/MAD), складывается с весами
  (`w_*` в настройках) → локальные максимумы = кандидаты.
- Если доступен LLM (Ollama или OpenAI-совместимый API) — он ранжирует кандидатов
  по расшифровке+чату, придумывает названия и причины. Без LLM всё работает на
  эвристике.

## Что появляется в `output/`

Результаты каждого VOD лежат в `output/<vod_id>/`:

```
metadata.json        данные VOD (title, канал, длительность)
chat.jsonl           чат: id, offset (секунда), user, text, emotes
chat.stats.json      статистика чата
chat.txt             читаемый лог чата (--dump-chat)
transcript.jsonl     расшифровка: start, end, text, translation
transcript.srt       субтитры SR              (для плееров)
transcript.txt       сплошной текст расшифровки
transcript.meta.json модель/язык/устройство/время распознавания
signals.json         карта интересности (скоры всех сигналов по окнам)
candidates.json      кандидаты до отбора
moments.json         финальные моменты (таймкод, score, категория, причина, chapter)
ai_summary.txt       резюме стрима от LLM (если LLM доступна)
report.md            отчёт для чтения
index.html           галерея с плеерами, таймкодами, чатом и расшифровкой
timecodes.txt        оглавление главами (мод toparachevt): "2:04:19 - Любимый цвет"
run_summary.json     сводка прогона
clips/*.mp4          нарезанные клипы
clips/*.jpg          превью
clips/*_vertical.mp4 вертикальные версии 9:16 (если --vertical)
work/                временные файлы (аудио WAV и т.п.)
```

Что можно делать с `moments.json`:

- **Править вручную** таймкоды/названия и пересобрать отчёт без повторного анализа:

  ```bat
  run.bat report 123456789
  ```

- **Донарезать** конкретные главы: `run.bat clip 123456789 --only 1 2 3`.
- **Забрать** данные в JSON через API галереи (см. ниже).

## Веб-галерея (`serve`)

Локальный сервер со списком всех обработанных VOD:

```bat
run.bat serve
:: или: python -m twitch_ai_clipper serve --host 127.0.0.1 --port 8765
```

Откройте в браузере **http://127.0.0.1:8765/** — список VOD (название, канал,
число моментов, ссылки на `report.md` и JSON). Каждая строка ведёт на
`/vod/<id>/index.html` — страницу с плеерами клипов, таймкодами со ссылками на
VOD, расшифровкой и выжимкой чата.

Маршруты API:

| Маршрут | Что отдаёт |
|---------|-----------|
| `GET /api/vods` | список VOD в JSON (+ сумма лайков) |
| `GET /api/vods/<id>/moments` | моменты конкретного VOD в JSON |
| `GET /api/vods/<id>/likes` | лайки клипов VOD: `{"<index>": count}` |
| `POST /api/vods/<id>/likes/<index>?action=up\|down` | поставить (+1) / снять (−1) лайк |
| `GET /vod/<id>/...` | статика папки VOD (`index.html`, `report.md`, клипы) |

### Лайки клипов

На карточке каждого клипа есть кнопка ♥ — она ставит/снимает лайк
(повторный клик снимает). Лайки хранятся в `output/<vod_id>/likes.json`
и доступны через API выше. Счётчик на лендинге показывает сумму лайков VOD.

Если `index.html` открыт двойным кликом (без сервера), лайки работают
локально через `localStorage` браузера — без общего счётчика, но состояние
сохраняется.

### Страница одного VOD без сервера

В папке `output/<vod_id>/` лежит готовый `index.html` (плееры + таймкоды + чат +
расшифровка). Его можно открыть двойным кликом прямо с диска — сервер не нужен.

## LLM: Ollama или OpenAI

LLM не обязательна: без неё работают эвристики. Но с моделью появляются
осмысленные названия, категории и переранжирование по смыслу.

Уровни провайдера (`--llm` / `llm_provider`):

| Значение | Поведение |
|----------|-----------|
| `auto` (по умолчанию) | сначала пробует Ollama, потом OpenAI-совместимый API |
| `none` | только эвристика, без модели |
| `ollama` | локальная модель через `http://127.0.0.1:11434` |
| `openai` | любой OpenAI-совместимый API (в т.ч. локальные сервера) |

Локально через Ollama:

```bat
ollama create Qwythos-9B-v2-Heretic:Q4_K_M -f Modelfile
run.bat run twitch.tv/канал --llm ollama --llm-model Qwythos-9B-v2-Heretic:Q4_K_M
```

Через OpenAI-совместимый API:

```bat
set OPENAI_API_KEY=sk-...
set OPENAI_BASE_URL=https://api.openai.com/v1
run.bat run 123456789 --llm openai --llm-model gpt-4o-mini
```

Перевод расшифровки на другой язык (тоже через LLM):

```bat
run.bat transcribe 123456789 --translate-to en
```

## Кастомная модель: Qwythos-9B-v2-Heretic (Q4_K_M)

По умолчанию пайплайн использует локальную модель
**`Qwythos-9B-v2-Heretic:Q4_K_M`** (задано в `llm_model`). Это кастомная
9B-модель в кванте `Q4_K_M` — компромисс между качеством русских заголовков
и памятью/скоростью.

### Что это и где взять

| Параметр | Значение |
|----------|----------|
| Имя модели в конфиге | `Qwythos-9B-v2-Heretic:Q4_K_M` |
| Источник (GGUF) | [WaveCut/Qwythos-9B-v2-Heretic-GGUF](https://huggingface.co/WaveCut/Qwythos-9B-v2-Heretic-GGUF) на HuggingFace |
| Файл для кванта `Q4_K_M` | `Qwythos-9B-v2-Heretic.Q4_K_M.gguf` |
| Размер на диске | ~5–6 ГБ (кванты: `Q4_K_M`, `Q5_K_M`, `Q6_K`, `Q8_0`) |
| Оперативка / VRAM | рекомендуется ≥ 8 ГБ (впрок на CPU или GPU) |

> Модель не из официального реестра Ollama, поэтому `ollama pull` для неё не
> работает — её нужно импортировать из скачанного GGUF (см. ниже).

### Установка (Windows)

1. Убедитесь, что [Ollama установлен](#установка-windows):
   ```bat
   winget install Ollama.Ollama
   ```
   После установки перезапустите терминал.

2. Скачайте GGUF-файл кванта `Q4_K_M` с HuggingFace
   ([страница модели](https://huggingface.co/WaveCut/Qwythos-9B-v2-Heretic-GGUF),
   файл `Qwythos-9B-v2-Heretic.Q4_K_M.gguf`) в любую папку, например
   `models\`.

3. Создайте `Modelfile` (в той же папке, что и GGUF) с одним содержимным:
   ```
   FROM ./Qwythos-9B-v2-Heretic.Q4_K_M.gguf
   ```

4. Импортируйте модель в Ollama:
   ```bat
   ollama create Qwythos-9B-v2-Heretic:Q4_K_M -f Modelfile
   ```
   Имя после `ollama create` должно **точно совпадать** со значением
   `llm_model` (включая `:Q4_K_M`).

5. Проверьте, что модель видна:
   ```bat
   ollama list
   ```
   В списке должна быть строка `Qwythos-9B-v2-Heretic:Q4_K_M`.

### Подключение к пайплайну

Модель подхватится автоматически при `llm_provider = "auto"` (или
`ollama`), если `llm_model = "Qwythos-9B-v2-Heretic:Q4_K_M"` — это значение
по умолчанию. Либо задайте явно:

```bat
:: в config.toml
[llm]
llm_provider = "ollama"
llm_model = "Qwythos-9B-v2-Heretic:Q4_K_M"

:: или флагом
run.bat run twitch.tv/канал --llm ollama --llm-model Qwythos-9B-v2-Heretic:Q4_K_M
```

### Другие кванты

Если `Q4_K_M` не хватает по качеству или наоборот не влезает по памяти —
возьмите другой квант из того же репозитория (`Q5_K_M`, `Q6_K`, `Q8_0`),
повторите шаги 3–4 с соответствующим `.gguf`-файлом и поменяйте тег в
`llm_model` (например `Qwythos-9B-v2-Heretic:Q8_0`).

### Если модель не грузится

| Симптом | Что делать |
|---------|------------|
| `ollama list` не показывает модель | переимпортируйте: имя в `ollama create` должно быть `Qwythos-9B-v2-Heretic:Q4_K_M` |
| `Ollama недоступен` в логах | запустите службу Ollama (`ollama serve` или иконка в трее), проверьте `http://127.0.0.1:11434` |
| Ollama роняет процесс при генерации | не хватает памяти: закройте другие приложения или возьмите кванты `Q4_K_M`/`Q5_K_M` |
| Медленные ответы на CPU | это нормально для 9B; уменьшите `llm_max_candidates`/`llm_batch` или используйте GPU |

## Нарезка клипов

- **Качество** — `--quality` (или `[cut] quality` в конфиге):
  `best`, `1080p60`, `1080p`, `720p60`, `720p`, `480p`, `360p`, `audio`.
- **Вертикальные 9:16** для Shorts/TikTok — `--vertical` (добавляет
  `clips/*_vertical.mp4`).
- **Субтитры** — `--burn-subs` вжигает текст из расшифровки в клип.
- **Точная резка** — `--precise-cut` (медленнее, но ровнее по кадрам).
- **Превью** — генерируются автоматически (`[cut] thumbnail = true`).
- **Число потоков** — `[cut] cut_workers` в конфиге (по умолчанию 2–3).
- **Приватные/закрытые VOD** — `--cookies-from-browser chrome`.

Только нарезка (без анализа), по своим таймкодам:

```bat
run.bat clip 123456789 --timecodes 0:10-0:45=Начало 2:00-2:30=Драма
run.bat clip 123456789 --timecodes-file chapters.txt --vertical --burn-subs
```

## Диагностика и решение проблем

```bat
python scripts/probe_env.py         :: ffmpeg/yt-dlp/Whisper/CUDA/LLM
python scripts/smoke_api.py <id>    :: метаданные + пробный чат на живом VOD
python scripts/diag_chat.py <канал> :: доступность чата на свежих VOD
python scripts/diag_fields.py <id>  :: какие поля схемы чата валидны
```

**Всегда запускайте через `run.bat`** — он включает UTF-8, поэтому кириллица в
консоли будет читаемой.

| Симптом | Причина / решение |
|---------|-------------------|
| `edges=0`, чат пустой | Схема Twitch изменилась: не должно быть неизвестных полей в запросе. Проверка: `python scripts/diag_fields.py <vod_id>` |
| Модель Whisper не грузится, висит | HF-транспорт «xet» блокируется. Уже отключён по умолчанию; зеркало: `--hf-endpoint https://hf-mirror.com` |
| `huggingface.co` недоступен | `python -m pip install openai-whisper` и `--asr-backend openai-whisper` (веса с CDN OpenAI) |
| `ffmpeg not found` | `winget install Gyan.FFmpeg` и перезапустить терминал |
| `OSError: ffmpeg/yt-dlp` | убедитесь, что `python -m pip install yt-dlp` актуален (CLI может отсутствовать — вызываем модулем) |
| Моментов ноль | добавьте `--max-clips 20 --top-candidates 60 --bucket 3`, проверьте `signals.json` |
| Кириллица в консоли «кракозябрами» | запускайте через `run.bat` (там ставится UTF-8) или `set PYTHONIOENCODING=utf-8` |
| Расшифровка покрывает не весь стрим | был указан `--limit-seconds`; перезапустите с `--force` (без `--limit-seconds`) |
| Клипы есть, но нет заголовков «по смыслу» | запустите Ollama и перезапустите `detect`/`report` с `--llm ollama` |

### Полезные приёмы

```bat
:: быстрый тест всего пайплайна на 10 минутах
run.bat run 123456789 --limit-seconds 600 --max-clips 5

:: подробный лог (отладка)
run.bat run 123456789 -v

:: переделать всё заново, игнорируя кеш
run.bat run 123456789 --force

:: свой конфиг
run.bat run 123456789 --config my-config.toml
```
